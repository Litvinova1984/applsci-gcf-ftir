# Public data boundary

This directory contains only the inputs required for the public reproducibility workflow.

- `pediatric/processed/`: de-identified active pediatric matrices, retained wavenumber grid, and the long-format analytical spectra needed for supplementary/reference projections.
- `pediatric/pediatric_metadata.csv`: study-local de-identified participant metadata used in the reported analyses.
- `technical_controls/`: four independent unused-strip DPT spectra.
- `adult/processed/`: de-identified 18 × 793 harmonized adult SNV matrix and retained wavenumber grid.
- `adult/aggregate/`: frozen aggregate adult axis-matching and clinical/domain summaries only.

Not distributed: raw OPUS archives, source-linked clinical records, adult source labels, individual-level adult clinical metadata, and private audit/provenance files.
